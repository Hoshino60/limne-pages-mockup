2. 作るページと設定値

作り方Aの準備（作り方Aのときだけ。1回だけ）

手順（2〜4が、作り方Aと作り方Bで違います。作り方Aの場合は、先に上の「作り方Aの準備」を行ってください）

  2. 「オンラインストア」→「テーマ」→ 公開中のテーマの「カスタマイズ」（画面によっては「テーマを編集」）→ 上部のページの選択で「ページ」→「テンプレートを作成」。名前は guarantee、元は「デフォルトのページ」
  3. 【作り方A】作ったテンプレートで「セクションを追加」→「LIMNE 保証ページの本文」を足し、ページのタイトルのセクションの直後に置きます。セクションの設定は既定のままです（表示するページのハンドルは 120-day-guarantee）。「保存」を押します。【作り方B】作ったテンプレートで「セクションを追加」→「カスタムLiquid」を足し、ページのタイトルのセクションの直後に置きます。カスタムLiquidの欄に、code/guarantee.liquid の中身をすべて貼り（手順書のページの8章の「コピー」、またはZIPの code フォルダのファイルをメモ帳で開いて全文をコピー）、「保存」を押します。本文の幅と余白は貼る中身で決めているので、セクションのほかの設定は既定のままにします
  4. 同じように、テンプレート reviews を作ります。【作り方A】「セクションを追加」→「LIMNE 口コミ・評判ページの本文」（口コミ10件と愛用者インタビュー4名が、ブロックとして最初から入っています）／【作り方B】code/reviews.liquid の中身を貼って保存します
  5. 「ページ」で2つのページを開き、「テーマテンプレート」をそれぞれ guarantee・reviews にして保存します（まだ非表示のまま）

公開中のテーマのまま作業して大丈夫な理由：新しいテンプレートは、割り当てたページにしか使われません。貼る中身は、ハンドルが 120-day-guarantee・reviews のページにしか出ないようにしてあります（ほかのページのURLに ?view=guarantee を付けても出ません）。ページは「表示」にするまで誰からも見えません。テーマエディタの中では、どのページで見ても本文が出るので、そこで見た目を確かめられます。作ったページのタイトル（h1）・パンくずと合わせて見るには、テーマエディタの上部のページの選択で、テンプレート guarantee・reviews を選び、プレビューするページに、作った非表示のページを選びます。
