施策管理表No.31「まくら一覧に『寝返りしやすい枕』の節と、マットレスへの導線を足す」の見本と手順です。ご確認いただくこと（1〜5）のお返事の前の、ご提案の版です。 お返事で作業の範囲が変わるため、お返事をいただいてから実装してください。見本は、2026年11月19日の公開中のページに変更を差し込んだもので、赤枠が足す・変える箇所です。

4. 進め方

テーマのファイルは足しません。テーマエディタの「カスタムLiquid」（まくらベーシックの商品ページで今も使っているものと同じ）に貼るだけで入れます。テーマの複製・コードの編集・新しいテンプレートは要りません。公開中のテーマで保存した時点で公開ページに出るため、②③④は公開の日に入れます。保存する前のテーマエディタの画面で、見た目を確かめられます。

  1. 作業1（計測）：5章のとおりGTMを設定します（リンクを押すとイベントが届く設定。リンクが出る前に設定しておいて問題ありません）
  2. 作業2（送り先の表現）：確認4のお返事のとおり、⑤を直します。直ったら、LANYが公開ページで確かめ、リンクを出してよい送り先をお伝えします
  3. 作業3（公開の日、②③）：「オンラインストア」→「テーマ」→ 公開中のテーマの「カスタマイズ」（画面によっては「テーマを編集」）→ 上部のページの選択で「コレクション」→ まくら一覧が使っているテンプレートを開きます（プレビューするコレクションを「まくら」にする）。「セクションを追加」→「カスタムLiquid」を足し、商品一覧のセクションの直後、ブランドの文（「LIMNE（リムネ）では…」の文章のセクション）の前に置きます。カスタムLiquidの欄に、code/pillow_list.liquid の中身をすべて貼ります（手順書のページの8章の「コピー」、またはZIPの code フォルダのファイルをメモ帳で開いて全文をコピー）
  4. 作業3（リンクの切り替え）：貼った中身の先頭にある {%- assign link_… = false -%} のうち、作業2で LANY がお伝えした送り先だけ false を true に書き換えます。false のままの送り先へのリンクは出ません（4つとも false なら、ボタンの並びごと出ません）。見た目を見本と比べてから「保存」を押します
  5. 作業3（公開の日、④）：同じく「カスタマイズ」で「商品」→ まくらベーシックが使っているテンプレートを開きます（プレビューする商品を「まくらベーシック」にする）。商品情報のセクションの「3・6・12回払いは本人確認が必要となります」のブロックの直後に「ブロックを追加」で、そのブロックと同じ種類のブロック（Liquid や HTML を書ける欄のあるもの。Impulse では「HTML」や「カスタムLiquid」などと表示されます。迷ったら、今の「3・6・12回払い」のブロックを開いて種類の名前を確かめてください）を足し、欄に code/pillow_basic_note.liquid の中身をすべて貼ります。マットレス一覧へのリンクは、link_mattress_list を作業4と同じように切り替えます。「保存」を押します
  6. 作業4：①のtitle・meta・h1を変えます（確認3のお返事のあと。「商品管理」→「コレクション」→「まくら」）

貼った中身は、ハンドルが pillow のコレクション・limne_pillow-basic の商品だけに出るようにしてあります。ほかのコレクション・商品が同じテンプレートを使っていても、文は出ません。ただし、テーマがブロックの外側に付ける枠は残るため、同じテンプレートを使うほかの商品があれば、余白が増えていないかを6章で確かめてください（まくらベーシックのテンプレートは pillow_new01 です。2026年11月19日の公開ページで確認）。あとでリンクを出すときは、同じカスタムLiquidの欄を開いて false を true にするだけです。

6. 公開前と公開後の確認

  • ②③④の文が、code/ のファイルと同じ。見た目が見本と同じ（パソコンとスマートフォン。見本はリンクをすべて出した状態です）
  • h1が1つだけ。出したリンクがすべて開く。LANYがお伝えした送り先だけにリンクが出ている
  • 他のコレクション（例：https://limne.jp/collections/mattress ）に②③が出ていない
  • まくらベーシックと同じテンプレート（pillow_new01）を使う商品がほかにあれば、その商品のページで、商品情報の「3・6・12回払い」の下の余白が、作業の前と変わっていない
  • GTMのプレビューで、③④のリンクを押すとイベントが1回ずつ届く。公開後は、GA4のリアルタイムで届く
  • Search Console の「URL検査」で、まくら一覧の「インデックス登録をリクエスト」を押す（LANYが行います）

8. ファイルの中身（コピー用）

どのファイルも「コピー」でクリップボードに入ります。一式は limne-pillow-shopify.zip でもダウンロードできます（フォルダの名前は手順書と同じ）。

貼るファイルは、Shopify公式の検査ツール Theme Check（3.30.1）でエラー0件です。警告は、愛用者インタビューの写真を、公式サイトの画像のURL（https://limne.jp/cdn/shop/… 。Shopifyの配信）で書いていることへの提案、リンクを /collections/… のように書いていることへの書き方の提案だけで、表示には影響しません。
